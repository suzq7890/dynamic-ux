Design Notes
Core UX Principle
Non-linear, context-driven: Users enter at any point. The interface adapts to what context exists — it never forces a sequential path. Every workshop card shows its status independently.
Entry Points
Any workshop can be the first: Orient, Frame, and Diverge & Converge all show as "Start" when no prior context exists for that workshop. The numbered order (1, 2, 3) is a suggested path, not a gate.
Action Unlocking
Context unlocks actions: Generated outputs (vibe coding prompt, lean business case, pro-forma) appear in the actions panel. Each shows its exact requirements. Actions with met requirements are clickable; unmet ones show what's still needed — they are never hidden.
D&C Without Prior Workshops
"Has D&C only" state: A user who enters at Diverge & Converge skips Orient and Frame entirely. Their D&C outputs still unlock the vibe coding prompt — a full business case is only partially available since it needs the problem statements.
Existing Materials
"Enter with existing context" pattern: Users with pre-existing artifacts (e.g., an existing problem statement) should be able to import / paste those in. The "Enter" CTA variant on workshop cards signals this — the user doesn't re-do the workshop, they supply the artifact.
What the Current Design Misses
Open questions for the design team:
  • How does a user import existing artifacts into a workshop?
  • What does "partial" D&C look like (concepts scored but features not yet prioritized)?
  • How does the dashboard communicate that skipped workshops can be added later?
  • Is the pro-forma always available post-Orient, or does it need financial inputs from a separate step?
